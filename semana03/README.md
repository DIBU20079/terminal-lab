# Semana 03 - Archivos, permisos y multiusuario

## Que hace

`organizar-archivos.sh` genera 50 archivos de prueba en `trabajo/`, los clasifica por extension en cinco categorias dentro de `organized/` y aplica a cada categoria los permisos que le corresponden.

## Archivos

- `organizar-archivos.sh` - script principal
- `README.md` - este archivo
- `trabajo/`  - 50 archivos de entrada generados por el script (no se versiona)
